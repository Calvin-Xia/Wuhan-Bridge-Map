# 武汉桥梁地图连线与证据区体验优化 Spec

日期：2026-07-13  
状态：设计已获用户批准，等待文档审阅

## 目标

围绕现有 8788 端口热更新页面完成三项优化：

1. 将桥梁点位调整到更接近桥面/河道中心的位置，新增二七长江大桥，并让 9 座桥形成一条连续的串联路线。
2. 采用用户选择的 A 方案，降低地图在工作区中的横向占比，缩短内容阅读与页面滚动距离。
3. 修复下方三个 ECharts 图表的注释可见性，重点改善中间饼图，并增加一次性的轻量图标放大动效与图表 hover/focus 强调。

## 范围与约束

- 只修改当前 Astro + TypeScript + MapLibre GL JS + ECharts 项目内的代码和静态数据。
- 8788 端口上的 dev 是热更新服务；实现和验证过程中不得停止或重启它。
- 保留现有 3 条调研路线；新增路线是桥梁串联线，不替换原路线。
- 所有坐标继续使用 GeoJSON/WGS84 的 `[longitude, latitude]` 顺序。
- 继续支持桌面端、移动端和 `prefers-reduced-motion`。
- 不新增后端、数据库、地图服务或构建依赖。

## 数据设计

### 桥梁点位

`public/data/bridges.geojson` 保持 `FeatureCollection<Point>` 结构。现有 8 座桥的点位更新为更接近桥梁中心的公开地理位置；新增：

- id：`erqi-yangtze-river-bridge`
- name：`二七长江大桥`
- river：`长江`
- openedYear：`2011`
- bridgeType：`公路桥`
- researchStatus：`资料整理中`
- 主题标签和故事字段使用与现有数据一致的研究占位表达。

点位校准参考公开的 OpenStreetMap/Mapcarta 地理标注和武汉市公开桥梁清单；页面不在运行时依赖这些外部页面。

### 故事与资料

`public/data/stories.json` 增加二七长江大桥的故事记录，使新增桥梁可以像其他点位一样展示故事面板。复用已有的 `source-bridge-catalog` 与 `field-template` 资料索引，不创建无证据的新来源。

### 连续桥梁路线

`public/data/routes.geojson` 增加一条 `route-bridge-chain`，几何类型为 `LineString`，使用与桥梁点位完全一致的中心坐标，顺序为：

1. 晴川桥
2. 武汉长江大桥
3. 鹦鹉洲长江大桥
4. 杨泗港长江大桥
5. 白沙洲长江大桥
6. 武汉长江二桥
7. 二七长江大桥
8. 天兴洲长江大桥
9. 青山长江大桥

该顺序表达从西北/中心区域进入南部桥群，再串到东北方向桥群的连续地理叙事。现有 `route-memory`、`route-public-space`、`route-network` 保持不变，但其端点会同步到更新后的桥梁中心点。

### 数据验证

补充数据测试，确保：

- 生产数据包含 9 座桥和二七长江大桥 id。
- 桥梁串联路线包含 9 个坐标，且与 9 个点位逐项对应。
- 每个故事仍引用存在的桥梁，每个桥梁的 source id 都存在。

## 地图实现

`src/scripts/map-app.ts` 继续由 MapLibre 负责渲染：

- 新增路线用双层线样式：低透明度的柔和底线 + 清晰的主线，和现有调研路线区分。
- 主线颜色使用 evidence 色系，现有调研路线仍使用各自 GeoJSON `color`。
- 新增桥梁自动进入列表、计数、标签、点击选择、故事面板与地图 marker，不增加专门的手写 UI 分支。
- marker 点击、列表点击、flyTo 和 popup 行为保持一致。

## 布局实现

采用 A「平衡双栏」：

- 桌面工作区使用约 42% 内容栏 + 58% 地图栏的网格比例。
- 地图高度从当前偏高值收窄到更紧凑的响应式区间，保证地图可读但不会成为页面滚动的主导区域。
- 左侧 `.story-rail` 保留目录与故事两段式结构，列表在自身容器内滚动。
- 980px 以下继续切换为单列：地图置顶，目录和故事在下方；560px 以下保留桥梁卡片横向滚动。
- 图表证据区的三列调整为更均衡的比例，减少中间图表被左右内边距挤压的情况。

## 图表实现

### 注释可见性

在 `src/scripts/charts.ts` 中：

- 柱状图继续显示轴标签和 tooltip，并为横轴标签提供稳定的可读空间。
- 中间饼图使用显式外置 label、引导线和可见 legend；标签 formatter 同时输出名称和百分比。
- 对窄容器使用边缘对齐/溢出保护，避免 `avoidLabelOverlap` 将注释全部隐藏。
- tooltip 继续保留，作为注释的补充而不是唯一信息来源。

### 动效

- 三个图表标题增加语义化小图标，使用 CSS 一次性 `chart-icon-pop` 动效，在 `.reveal.is-visible` 时触发。
- 饼图数据项在 hover/focus 时使用 ECharts emphasis 做轻微放大和阴影强调。
- `prefers-reduced-motion: reduce` 时关闭动画并保持标签、图标完整可见。
